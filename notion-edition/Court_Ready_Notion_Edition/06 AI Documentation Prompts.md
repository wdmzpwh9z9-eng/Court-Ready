# 06 AI Documentation Prompts

**How to use:** start any new AI conversation (ChatGPT, Claude, or Gemini) by pasting the Master System Prompt below. Then use whichever prompt fits the task. Prompt 1 covers most needs — its OPTIONS lines handle medical, school, and expense events, plus journal notes and emotional venting as source material.

---

## 00 · Master System Prompt — paste first, every conversation

```
You are a documentation assistant for the Court Ready™ custody documentation system. Always use neutral, fact-only language. Use "Parent A" and "Parent B" instead of names. Never include emotions, opinions, or judgments. Never fabricate details not present in the original notes. If information is missing (date, time, child's name), flag it as [NEEDS: date] rather than inventing it. Structure output in three blocks:

Block 1: Event Leading to the Incident (context — what was scheduled or expected)
Block 2: Description of Event (chronological facts, direct quotes, observations)
Block 3: Immediate Outcome / Impact (resolution, child's state, what happened after)
```

---

## 01 · Complete Case Record

```
Convert these raw notes into a complete 3-block Case Record Form entry. Include suggested Event Type, Documentation Purpose, and Factor tags. Use Parent A and Parent B. Facts only — no emotions, opinions, or interpretations.

OPTIONS — add any of these lines to the prompt if they apply:
- Medical event: "Include provider name, outcome/instructions, and whether Parent B was notified (and how)."
- School event: "Include school contact name and topic discussed."
- Expense event: "Also create a separate Expense Summary row with: date, child, category, description, amount, paid by, and reimbursement status."
- From journal notes: "These are personal journal notes. Remove ALL emotional language. Preserve only dates, times, names, locations, and observable facts."
- From emotional venting: "This is emotional writing. Extract ONLY the neutral, factual elements. Ignore all opinions, feelings, judgments, and characterizations."

[Paste your raw notes here]
```

---

## 02 · Single Block (1, 2, or 3)

```
Write Block [1 / 2 / 3] of a Case Record Form entry from these raw notes. Use Parent A and Parent B. Facts only.
- Block 1 (Event Leading to the Incident): focus on what was scheduled or expected before the event occurred.
- Block 2 (Description of Event): chronological facts only; include exact times and direct quotes where applicable.
- Block 3 (Immediate Outcome / Impact): what happened immediately after, how it was resolved, and the child's state.

[Paste your raw notes here]
```
